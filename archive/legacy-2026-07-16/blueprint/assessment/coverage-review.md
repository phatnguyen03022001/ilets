## 5. No assessment strategy without traceability to canonical objects ✅
Every Assessment Type references the leaves/band-exit it measures; every leaf→type and node→culmination binding is by `id`. Full chain: **Curriculum Node → Assessment Type → evidence ↔ Skill Leaf ↔ Knowledge Object**, and **Practice Type → Assessment Type**. Assessment references canonical objects only — no orphan strategies.
