# Learning

## Purpose
Define the governing **learning model** — the foundation every other Blueprint section implements. Per Founder directive: *the band model implements the learning foundation; it does not define it.* `bands/`, `skills/`, `knowledge/`, `curriculum/`, `practice/`, `assessment/`, and `progress/` must conform to this section.

## Scope (the 9 elements)
1. Learning philosophy — [philosophy.md](philosophy.md) *(drafted: Founder-decided principles; evidence synthesis pending)*
2. Mastery model — how mastery/competence is defined and demonstrated. *(pending research)*
3. Prerequisite model — how prerequisites and learning progressions are structured. *(pending research)*
4. Progression model — how learners advance (mastery-gated vs. adaptive). *(pending research + Founder fork)*
5. Practice model — design of practice (retrieval, spacing, interleaving, scaffolding, feedback timing). *(pending research)*
6. Assessment philosophy — formative vs. summative; criterion-referenced; feedback. *(pending research)*
7. Review philosophy — spaced review, forgetting, consolidation. *(pending research)*
8. AI's role in learning — augmentation boundaries and effectiveness. *(pending research + Founder fork)*
9. Content hierarchy — how content is organized and prioritized. *(pending research)*
